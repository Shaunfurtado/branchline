## Final proof points

1. **Strong fit for WebMCP:** multi-step semantic work over one live page state, with changing capabilities and a human authority boundary.
2. **Better experience:** typed tools compress investigation while visible causal motion keeps the person oriented.
3. **New human–agent collaboration:** a person edits intent directly; the agent replans against that exact change; stale execution capability disappears.
4. **Implementation:** direct imperative registration, strict schemas, runtime validation, AbortController lifecycle, annotations, shared store, structured outputs, verification, and rollback.

Do not add unmeasured speed, click-reduction, accuracy, or ROI claims. Keep the synthetic-data disclosure and browser-support limitation.
